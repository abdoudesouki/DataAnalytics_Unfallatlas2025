<h1 id="Projektbeschreibung">Projektbeschreibung¶</h1><h2 id="Analyse-t%C3%B6dlicher-Verkehrsunf%C3%A4lle-in-Deutschland">Analyse tödlicher Verkehrsunfälle in Deutschland¶</h2><h3 id="1.-Projekt%C3%BCbersicht">1. Projektübersicht¶</h3><p>In diesem Projekt werden tödliche Verkehrsunfälle in Deutschland mithilfe von Daten aus dem Unfallatlas 2025 analysiert. Ziel ist es, zeitliche, regionale und verkehrsbezogene Muster zu identifizieren und mögliche Zusammenhänge zwischen verschiedenen Unfallmerkmalen zu untersuchen.</p> <p>Der Schwerpunkt liegt auf der explorativen Datenanalyse (Exploratory Data Analysis, EDA) und der Visualisierung der Ergebnisse mit Python.</p> <hr /> <h2 id="2.-Zielsetzung">2. Zielsetzung¶</h2><p>Das Hauptziel des Projekts ist es, anhand der Unfallatlas-Daten zu untersuchen, wann, wo und unter welchen Bedingungen tödliche Verkehrsunfälle besonders häufig auftreten.</p> <p>Dabei sollen insbesondere folgende Fragestellungen beantwortet werden:</p>
  • An welchen Wochentagen ereignen sich die meisten tödlichen Verkehrsunfälle?
  • Gibt es Unterschiede zwischen den einzelnen Monaten?
  • Zu welchen Tageszeiten treten besonders viele tödliche Unfälle auf?
  • Wie häufig waren Fahrräder, Pkw, Fußgänger, Motorräder und Güterkraftfahrzeuge an Verkehrsunfällen beteiligt?
  • Wie häufig treten die verschiedenen Verkehrsteilnehmergruppen – Fußgänger, Radfahrer, Pkw, Güterkraftfahrzeuge (Gkfz), Krafträder (Krad) und sonstige Verkehrsmittel (e.g. Bus, Tram etc) – gemeinsam in Verkehrsunfällen auf?
  • Gibt es regionale Unterschiede zwischen Bundesländern?
  • Lassen sich räumliche Unfallhäufungen bzw. Hotspots erkennen?
  • Wie verteilen sich tödliche Unfälle auf Tageslicht und Verkehrsteilnehmergruppen?
  • Gibt es Zusammenhänge zwischen Wochentag, Tageszeit?
<h2 id="3.-Datengrundlage">3. Datengrundlage¶</h2><p>Als Datengrundlage wird der Unfallatlas 2025 verwendet. Der Datensatz enthält Informationen zu Verkehrsunfällen mit Personenschaden in Deutschland.</p> <p>Für die Analyse werden ausschließlich Unfälle mit Getöteten betrachtet.</p> <p>Besonders relevante Variablen sind:</p> <thead> <th>Variable</th> <th>Bedeutung</th> </thead> <tbody> </tbody> <tbody></tbody>

import pandas as pd
import plotly.express as px

# Define the 4-hour periods
def zeitperiode(stunde):
    if 2 <= stunde <= 5:
        return "02–05"
    elif 6 <= stunde <= 9:
        return "06–09"
    elif 10 <= stunde <= 13:
        return "10–13"
    elif 14 <= stunde <= 17:
        return "14–17"
    elif 18 <= stunde <= 21:
        return "18–21"
    else:  # 22, 23, 0, 1
        return "22–01"

df["Zeitperiode"] = df["USTUNDE"].apply(zeitperiode)

# Count accidents per period
counts = df["Zeitperiode"].value_counts()

# Keep chronological order
order = ["02–05", "06–09", "10–13", "14–17", "18–21", "22–01"]
counts = counts.reindex(order)

# Calculate percentages
pct = counts / counts.sum() * 100

# Create labels containing percentage and number
labels = [
    f"{period}: {pct[period]:.1f}% ({counts[period]:,})"
    for period in order
]

# Pie chart
fig = px.pie(
    values=counts.values,
    names=labels,
    title="Verteilung der Verkehrsunfälle nach 4-Stunden-Zeiträumen",
    hole=0
)

fig.update_traces(
    textinfo="percent",
    hovertemplate="<b>%{label}</b><br>Anzahl: %{value:,}<br>Anteil: %{percent}<extra></extra>"
)

fig.update_layout(
    title_x=0.5,
    width=800,
    height=600
)

fig.show()
